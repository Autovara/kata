### kata --help
usage: kata [-h] [--version] {king,lane,submission,challenge,plugin} ...

Initialize and evaluate subnet-pack coding-agent competition lanes.

positional arguments:
  {king,lane,submission,challenge,plugin}
    king                Manage the current king agent for a lane.
    lane                Manage evaluator-backed subnet packs and the central
                        pack registry.
    submission          Manage miner agent submissions for PR-based
                        competition.
    challenge           Score the king against several candidates on the same
                        projects and rank them.
    plugin              Query an installed subnet plugin.

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit

### kata challenge --help
usage: kata challenge [-h] --evaluator EVALUATOR --king-path KING_PATH
                      --candidate ID=PATH
                      [--challenge-cache-path CHALLENGE_CACHE_PATH]
                      [--output-root OUTPUT_ROOT]
                      [--challenge-progress-path CHALLENGE_PROGRESS_PATH]
                      [--challenge-config-json CHALLENGE_CONFIG_JSON] [--json]

options:
  -h, --help            show this help message and exit
  --evaluator EVALUATOR
                        Subnet evaluator id whose plugin runs the challenge.
  --king-path KING_PATH
                        Path to the current lane king artifact.
  --candidate ID=PATH   A competing candidate as '<submission-id>=<artifact-
                        path>'. Repeat per entrant.
  --challenge-cache-path CHALLENGE_CACHE_PATH
                        Optional evaluator-owned cache path for this
                        challenge.
  --output-root OUTPUT_ROOT
                        Optional base directory for challenge artifacts.
                        Defaults to ./runs.
  --challenge-progress-path CHALLENGE_PROGRESS_PATH
                        Optional path to publish a live per-candidate progress
                        snapshot for the dashboard.
  --challenge-config-json CHALLENGE_CONFIG_JSON
                        Optional JSON object merged into the selected
                        evaluator's challenge configuration. Used by multi-
                        lane operators to keep plugin settings lane-scoped.
  --json                Emit machine-readable JSON instead of text.

### kata lane init --help
usage: kata lane init [-h] --lane-id LANE_ID [--subnet-pack SUBNET_PACK]
                      [--repo-pack SUBNET_PACK] [--mode MODE]
                      --evaluator-id EVALUATOR_ID
                      [--policy-version POLICY_VERSION] [--inactive]
                      [--public-root PUBLIC_ROOT] [--json]

options:
  -h, --help            show this help message and exit
  --lane-id LANE_ID     Lane id, e.g. sn60__bitsec.
  --subnet-pack SUBNET_PACK
                        Subnet pack id. Defaults to lane id.
  --repo-pack SUBNET_PACK
                        Deprecated alias for --subnet-pack.
  --mode MODE           Submission mode for the lane.
  --evaluator-id EVALUATOR_ID
                        Evaluator adapter id for the lane, e.g. sn60_bitsec.
  --policy-version POLICY_VERSION
                        Evaluator policy version recorded in lane metadata.
  --inactive            Register the lane without activating it.
  --public-root PUBLIC_ROOT
                        Optional Kata root that owns the lanes directory.
  --json

                        avatar lookup.
  --title TITLE         Optional submission title.
  --notes NOTES         Optional short notes.
